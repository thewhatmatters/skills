# Decision escalator

When any bot’s work is blocked on Randy’s go/no-go (freeze, “holding until you say”, waiting on approval):

1. Do **not** leave a buried status line (“holding”, “waiting on Randy”) as the only signal.
2. Send Randy one **1:1** message with **one concrete ask** (Yes/No or a single choice), naming: what’s blocked, who owns it, what happens if yes, what happens if no/skip.
3. Prefer a question widget with ≤6 options when the ask is a real decision.
4. If multiple items are blocked, escalate **one cluster per turn** — do not bundle unrelated decisions so a skip kills the whole batch.
5. After Randy answers, resume the owning bot with the decision; do not re-ask.

Use this whenever you catch yourself writing “holding until Randy says go” without a ping.
